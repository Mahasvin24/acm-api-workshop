        Registration rules & editing
        

          Name: 3–48 characters. Creator: 2–48. Description: 10–160. Single-line
          plain text. IPv4 only; no localhost. Port: 1024–65535. Each name and
          IP + port must be unique.
        

        

          Use PATCH /api/apis/YOUR_ID with only the fields you want
          to change, or DELETE /api/apis/YOUR_ID to remove it. For
          both, add Authorization: Bearer YOUR_EDIT_TOKEN.
        

        

          Cross-origin requests are allowed. Browser mixed-content or
          local-network permissions can still block calls to classmates’ HTTP
          servers; use Postman’s desktop app for the workshop.
